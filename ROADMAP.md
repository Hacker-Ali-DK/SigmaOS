# Roadmap

## CURRENT (IMPLEMENTED)
- Offline Solar Prayer calculations with exact astronomical formulas.
- Event Bus micro-architecture with robust causal depth checking and IndexedDB persistence.
- Deterministic Deen, Discipline, and Wellness scoring engines with dynamic redistribution.
- Sleep architecture, habit, and goal tracking.
- Fully offline IndexedDB persistence with v5 legacy migration support.
- Heuristic-based AI data preparation (Context Builder, Correlation Engine).

## PLANNED
- **LLM Integration:** Connect the `CompressedContext` string to a local or external LLM API for generative AI Coach conversations.
- **Dynamic AI Recommendations:** AI-driven schedule and routine optimization based on Pearson R correlations.
- **Semantic Memory Extraction:** Replace regex-based memory parsing with LLM-powered fact extraction.
- Automated CI/CD Testing Framework integration (Jest/Vitest).

## NOT IMPLEMENTED
- Multi-device Cloud Sync (Serverless).
- User Authentication/Accounts.
- Social sharing or leaderboards.
- Backend database integration (PostgreSQL, Firebase).
